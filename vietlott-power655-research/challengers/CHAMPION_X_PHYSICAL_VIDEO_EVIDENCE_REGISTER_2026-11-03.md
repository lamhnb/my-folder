## Required frame-level extraction workflow
For each candidate:
1. Confirm it is the **full original draw** (not results slideshow, redraw, trial draw, highlight, audio dubbing, or a simulcast with cuts).
2. Match on-screen draw ID and date to a known official result; record original source URI and available file digest.
3. Record **timecode for each visibly emitted physical ball** and label 1..7; if cut/blurred/unreadable then mark missing, NOT guess.
4. Record source evidence for machine label, case/valise label, operating mode, interruption, trial draw and maintenance if visible. Use UNKNOWN otherwise.
5. Second independent reviewer checks 7-ball order and correspondence to official unordered winning six + special.
6. Only when 2 reviewers agree and all 7 physical ball numbers are observed, set `physical_order_verified=true`.

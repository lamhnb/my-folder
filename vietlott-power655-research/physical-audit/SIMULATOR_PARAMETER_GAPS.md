## What can use the recovered data now

Metadata can cite MAGNUM II and the newer source. The existing nominal ball scenario is corroborated. A future separate geometry scenario can test the documented mixing diameter after resolving surface meaning; all numerical checks would need repeating after such a change. New case-code observations can support a provisional video cohort index. None supplies measured per-number physical coefficients.

The current code samples ball radii/masses by physical ID before assigning printed labels using an independent stream. There is no configuration field importing 55 measured property records keyed by certified set and printed number. Such an importer requires a defined identity join and new implementation/testing; it is not created in this audit. Synthetic rank-to-position B1 mappings on the separate protocol branch are not documented Vietlott loading mechanics. G09/G13.

## Capability limits

1. **Approximate runnable simulation:** possible and already implemented. Missing data limit fidelity, not the ability to run.
2. **Calibration to real footage:** nominal scale/model recovered, but full dynamics remain underidentified. Need metric geometry/depth, calibrated cameras, identified motion, gates/control logs and material experiments. No unique fit follows from downstream intervals.
3. **Persistent mechanical bias:** requires serial/set/physical-ball continuity and enough independently validated draws across maintenance periods. Otherwise apparent persistence may be loading, arbitrary labels, geometry assumptions, selection law or solver order. The model's insertion-order sensitivity already demonstrates this risk.
4. **Pre-close forecasts:** require inputs that demonstrably exist before ticket issuance closes, plus preregistered independent evaluation against uniform/B1/B7 under the same ticket budget. R10 p5 places system locking before case selection. Case markings learned from preparation broadcasts cannot be backdated into a forecast.

The existing 78-run results, small timestep/solver comparisons, label permutation/repeat tests and simulated perturbations concern the hypothetical model. They do not establish calibrated real selection probabilities, actual mechanical bias or a Jackpot advantage. This audit does not rescore lottery outcomes or tune physics to winning numbers.
